Privacy Policy — Work-Time Monitor

Effective date: August 25, 2026

Work-Time Monitor is a workplace time-monitoring extension intended for authorized teams and devices.

Information handled

After the user affirmatively activates the extension, it reads the visible work-status value needed to determine connected work time on the authorized work portal. It also handles timestamps, extension version, and a device activation identifier used to associate the installation with the administrator's dashboard.

Information not collected

The extension does not record calls, microphone audio, camera video, screenshots, keystrokes, message content, work-platform account names or IDs, passwords, emails, or unrelated browsing activity.

How information is used

Status values and timestamps are used only to calculate connected work time, display connection state, maintain the extension's operation, and provide authorized workplace reporting to the administrator who issued the activation code.

Data transmission

Monitoring data is transmitted over HTTPS to the extension's backend, which uses Supabase infrastructure. The authorized administrator can view connected-time information in the administration dashboard. Data is not sold and is not used for advertising, profiling, credit decisions, or unrelated purposes.

Retention and deletion

Monitoring records are retained until the authorized administrator deletes the associated employee/device record. An administrator may deactivate a device while retaining historical records, or permanently delete the device record and its associated monitoring history.

Security

Each installation uses a device-specific activation credential. Network transmission uses HTTPS. The extension does not contain an administrator password or backend service-role credential.

User choice and consent

Monitoring does not begin until the user enters a valid activation code, reviews the in-extension disclosure, checks the consent box, and activates the extension. Removing the extension stops monitoring on that Chrome installation.

Limited Use

Information received through Chrome APIs and authorized website access is used only to provide and improve the extension's single purpose: connected work-time monitoring and reporting. Data is not transferred for advertising, personalized marketing, or unrelated purposes.

Contact

For access, correction, deletion, or privacy questions, contact the workplace administrator who provided the activation code or use the support channel associated with the Chrome Web Store listing.
